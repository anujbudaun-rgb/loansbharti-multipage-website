Files included:

- styles.css: layout, mobile styling, ticker and animations
- script.js: mobile menu, scroll reveal, copyright year
- images/: LoansBharti logo and hero visual
- privacy-policy.html, terms.html, thank-you.html

HOW TO DEPLOY
1. Extract this ZIP on your phone/computer.
2. Upload all files and the images folder to the ROOT of your GitHub repository. Keep the file/folder names unchanged.
3. If using Netlify, choose Deploy manually and upload the extracted folder contents, or connect the GitHub repository.
4. If using Vercel, import the GitHub repository as a static site; no build command is required.
